# Communications-Mathematics

기통수2 중간고사 문제은행 — 고려대학교 차세대통신학과 **기초통신수학 II (미적분학)** 중간고사 대비 사이트예요.
시험 범위 **Ch.12 벡터 ~ 16.4 그린 정리**의 개념 정리 한 페이지, 1~4단계 문제 은행(1·2단계 120문제, 3·4단계 126문제, 총 492문제 · 14~16장 위주), 중간고사 모의고사 A–E 5세트(세트마다 10문항 · 15개 주제)로 구성돼요.

사이트 주소 (GitHub Pages): https://foy1229-maker.github.io/Communications-Mathematics/

3·4단계에는 121~126번으로 **미분가능성의 정의**(14.4, 정의 7의 ε₁·ε₂ · 일변수 증분식 · 미분불가능 반례) 3문제와 **u·v 변수변환**(15.9, 야코비안) 3문제를 더 넣었어요. 두 유형은 수업 자료(강의 예제·과제)에는 없어서 교재와 수업 중 설명을 바탕으로 만들었고, 문제 출처와 개념 페이지에 '수업 자료 밖'으로 표시했어요.

12·13장은 14~16장 문제를 풀 수 있을 정도의 계산(직선·평면·외적·곡선)만 다루고, 나머지는 14~16장이에요.

모든 정답은 계산기 없이 손으로 구할 수 있는 정확한 값(분수·근호·π·e·ln)이에요.

모의고사 A~E 세트(`mock.html?set=1~5`)는 세트마다 아래 15개 주제를 10문항에 빠짐없이 담았어요. 75~90분 시험에서 평균 70점 정도를 목표로 소문항 배점과 계산량을 맞췄고(문항마다 권장 풀이 시간, 합 81분), 단원 순서는 섞어 배치했어요. 세트마다 같은 주제를 다른 조합·다른 숫자로 묶었어요.

1. 극좌표 꽃잎(장미곡선) 이중적분 · 2. 라그랑주 승수법 · 3. 다변수 극한의 존재성 · 4. 미분가능성의 정의(Δz = f_xΔx + f_yΔy + ε₁Δx + ε₂Δy, B·E세트에는 일변수 증분식 포함) · 5. 원주좌표 삼중적분 · 6. 구면좌표 삼중적분 · 7. u·v 변수변환(야코비안) · 8. 적분 순서 바꾸기(이중·삼중) · 9. 그린 정리와 곡선을 나누어 직접 계산(두 방법) · 10. 편도함수와 그래디언트 · 11. 곡선의 길이 · 12. 연쇄법칙 · 13. 스칼라 사영·벡터 사영(comp·proj) · 14. 접평면과 그래디언트 · 15. 2계 도함수 판정법(극값·안장점)

## 풀이 기록

로그인 없이 바로 열려요. 맞음/다시 풀기 기록은 **이 브라우저(localStorage)에만** 저장되고 어디로도 보내지 않아요(다른 기기·브라우저와는 공유되지 않아요).

- 예전 로그인 기능으로 계정마다 따로 저장했던 기록은 사이트를 처음 열 때 하나로 합쳐져요(마지막으로 로그인했던 계정 기록이 먼저). 합친 뒤 남아 있던 계정 · 로그인 정보는 지워요.
- `login.html`은 예전 주소(즐겨찾기 등)로 들어와도 원래 가려던 페이지나 대시보드로 바로 넘어가게만 남겨 뒀어요.

## 문제 수정·추가

문제 원본은 `tools/levelN.py`(처음 30문제)와 `tools/levelN_c1213.py` · `_c14.py` · `_c15.py` · `_c16.py`(단원별 추가 90문제, N = 1~4)에 있고(3·4단계 121~126번은 `_c14.py` · `_c15.py` 끝), 문제마다 sympy로 정답을 다시 계산하는 `check`가 붙어 있어요. 공통 정의(단원·소단원·유형·단계)는 `tools/bank_lib.py`.

모의고사 A~E 세트 원본은 `tools/mock_sets.py`예요. 문항마다 sympy·mpmath로 정답을 다시 계산하는 `check`가 붙어 있고(가능하면 원래 좌표·원래 적분 순서의 수치 적분으로도 한 번 더 확인), `build.py`가 세트마다 10문항인지, 15개 주제(`TOPICS`)가 모두 들어 있는지, 권장 시간 합이 75~90분인지 확인해요.

```bash
pip install sympy mpmath
python3 tools/build.py            # 492문제 정답 확인 → assets/problems.js
                                  # 모의고사 A~E 세트 정답·구성 확인 → assets/mock-problems.js
python3 tools/build.py --partial  # 작업 중: 문제 수가 아직 안 맞는 단계는 개수 확인을 건너뜀
python3 tools/devcheck.py level4_c14   # 파일 하나만 빠르게 검산
python3 tools/mock_sets.py             # 모의고사 A~E 세트만 빠르게 검산
```

### 인쇄용 PDF

모의고사 세트는 A4 시험지(문항당 한 쪽, 풀이 공간과 답란)와 정답 및 풀이(빠른 정답표 포함) PDF로 뽑을 수 있어요. Playwright(Chromium)와 KaTeX가 필요해요.

```bash
python3 tools/print_sets.py --sets c d e --out print/   # 세트 id: a b c d e
# → print/기통수2 모의고사 C세트 시험지.pdf · …정답풀이.pdf
```

`assets/problems.js`, `assets/mock-problems.js`는 자동 생성 파일이라 직접 고치지 말고 `tools/` 쪽을 고친 뒤 다시 빌드하세요.
`build.py`는 단계별 문제 수(1·2단계 120, 3·4단계 126), 단원별 문항 수, 번호 누락, 모든 출제 유형에 문제가 1개 이상 있는지, 모의고사 세트마다 10문항 · 15개 주제 · 권장 시간 75~90분인지도 함께 확인해요.

## 구성

```
index.html          대시보드
concepts.html       개념 정리 · 출제 유형
bank.html           문제 은행 (?level=1..4)
mock.html           모의고사 (?set=1~5 → A~E세트)
login.html          예전 로그인 주소 → 대시보드로 넘기기만 해요
assets/
  site.css          개념·문제 은행·모의고사 공통 스타일
  common.js         수식 렌더링(KaTeX), 풀이 기록 저장 (이 브라우저), 예전 계정별 기록 합치기
  bank.js           문제 은행 화면
  concepts.js       유형별 연습 문제 링크, 목차 표시
  mock.js           모의고사 화면 (세트 탭, 풀이 시간, 기록, 출제 구성표, 문항 바로가기)
  problems.js       문제 데이터 (자동 생성)
  mock-problems.js  모의고사 데이터 (자동 생성)
  img/              고려대 엠블럼, 본관 배경 사진, 파비콘
tools/              문제 원본(level*.py, mock_sets.py)과 정답 검증·빌드 스크립트(build.py, devcheck.py), 인쇄용 PDF(print_sets.py), 파비콘 만들기(make_icons.py)
```

파비콘은 세로로 긴 엠블럼을 정사각형 캔버스 가운데에 비율 그대로 놓은 것이에요(탭에서 찌그러지지 않게). 엠블럼을 바꾸면 `python3 tools/make_icons.py`로 다시 만들어요.

수식은 KaTeX, 글꼴은 Pretendard를 jsDelivr CDN에서 불러와요.
수업 자료의 강의 예제·복습문제·과제 유형을 바탕으로 새로 만든 개인 학습용 문제예요.
