# Communications-Mathematics

기통수2 중간고사 문제은행 — 고려대학교 차세대통신학과 **기초통신수학 II (미적분학)** 중간고사 대비 사이트예요.
시험 범위 **Ch.12 벡터 ~ 16.4 그린 정리**의 개념 정리 한 페이지, 1~4단계 문제 은행(단계당 120문제, 총 480문제 · 14~16장 위주), 모의고사 6회분(예상 모의고사 10 + 5문항, 실전 모의고사 1~5회 각 10문항)으로 구성돼요.

사이트 주소 (GitHub Pages): https://foy1229-maker.github.io/Communications-Mathematics/

| 단계 | 성격 | 단원별 문항 수 |
|---|---|---|
| 1단계 · 기본 | 공식 바로 적용 | Ch.12 8 · 13 6 · 14 46 · 15 36 · 16 24 |
| 2단계 · 표준 | 강의 예제·과제 유형 (숫자만 바꾼 유사 문항) | 같음 |
| 3단계 · 응용 | 복습문제·기출(2022·2024·2025) 유형 | 같음 |

12·13장은 14~16장 문제를 풀 수 있을 정도의 계산(직선·평면·외적·곡선)만 다루고, 나머지는 14~16장이에요.

모든 정답은 계산기 없이 손으로 구할 수 있는 정확한 값(분수·근호·π·e·ln)이에요.

예상 모의고사(`mock.html`)는 예상 유형 10개(극좌표 이중적분, 극한과 연속, 접평면·법선, 라그랑주 승수법, 이중적분, 삼중적분, 방향도함수·그래디언트, 선적분의 기본정리, 그린 정리, 최대 증가 방향)를 2025학년도 Calculus II(MATH 162, 다른 교수님) 중간·기말고사 난이도에 맞춰 만든 문제예요. 추가 5문항은 그 시험에 나왔지만 예상 목록에 없던 극값·안장점, 닫힌 영역의 최댓값·최솟값, 2계 연쇄법칙, 음함수 미분·선형근사, 12–13장 직선·평면·벡터함수예요.

실전 모의고사 1~5회(`mock.html?set=1..5`)는 2022·2024·2025학년도 미적분학 II 중간·기말고사(공과대학·생명과학대학, 다른 교수님)의 문항 구성을 따라 숫자와 조건을 바꿔 새로 만든 문제예요. 시험 범위가 16.4까지라 회차마다 선적분의 기본정리·그린 정리 문항을 넣었어요.

## 풀이 기록

로그인 없이 바로 열려요. 맞음/다시 풀기 기록은 **이 브라우저(localStorage)에만** 저장되고 어디로도 보내지 않아요(다른 기기·브라우저와는 공유되지 않아요).

- 예전 로그인 기능으로 계정마다 따로 저장했던 기록은 사이트를 처음 열 때 하나로 합쳐져요(마지막으로 로그인했던 계정 기록이 먼저). 합친 뒤 남아 있던 계정 · 로그인 정보는 지워요.
- `login.html`은 예전 주소(즐겨찾기 등)로 들어와도 원래 가려던 페이지나 대시보드로 바로 넘어가게만 남겨 뒀어요.

## 문제 수정·추가

문제 원본은 `tools/levelN.py`(처음 30문제)와 `tools/levelN_c1213.py` · `_c14.py` · `_c15.py` · `_c16.py`(단원별 추가 90문제, N = 1~4)에 있고, 문제마다 sympy로 정답을 다시 계산하는 `check`가 붙어 있어요. 공통 정의(단원·소단원·유형·단계)는 `tools/bank_lib.py`.

예상 모의고사 원본은 `tools/mock.py`(`check_all()`이 소문항 정답 70개 검산), 실전 모의고사 1~5회는 `tools/mock_sets.py`(문항마다 `check`)에 있어요.

```bash
pip install sympy mpmath
python3 tools/build.py            # 480문제 정답 확인 → assets/problems.js
                                  # 모의고사 6회분 정답 확인 → assets/mock-problems.js
python3 tools/build.py --partial  # 작업 중: 120문제가 안 된 단계는 개수 확인을 건너뜀
python3 tools/devcheck.py level4_c14   # 파일 하나만 빠르게 검산
```

`assets/problems.js`, `assets/mock-problems.js`는 자동 생성 파일이라 직접 고치지 말고 `tools/` 쪽을 고친 뒤 다시 빌드하세요.
`build.py`는 단계당 120문제, 단원별 문항 수, 번호 누락, 모든 출제 유형에 문제가 1개 이상 있는지, 모의고사 회차마다 10문항인지도 함께 확인해요.

## 구성

```
index.html          대시보드
concepts.html       개념 정리 · 출제 유형
bank.html           문제 은행 (?level=1..4)
mock.html           모의고사 (예상 · ?set=1..5 실전)
login.html          예전 로그인 주소 → 대시보드로 넘기기만 해요
assets/
  site.css          개념·문제 은행·모의고사 공통 스타일
  common.js         수식 렌더링(KaTeX), 풀이 기록 저장 (이 브라우저), 예전 계정별 기록 합치기
  bank.js           문제 은행 화면
  concepts.js       유형별 연습 문제 링크, 목차 표시
  mock.js           모의고사 화면 (회차 탭, 풀이 시간, 기록, 문항 바로가기)
  problems.js       문제 데이터 (자동 생성)
  mock-problems.js  모의고사 데이터 (자동 생성)
  img/              고려대 엠블럼, 본관 배경 사진, 파비콘
tools/              문제 원본(level*.py, mock.py, mock_sets.py)과 정답 검증·빌드 스크립트(build.py, devcheck.py), 파비콘 만들기(make_icons.py)
```

파비콘은 세로로 긴 엠블럼을 정사각형 캔버스 가운데에 비율 그대로 놓은 것이에요(탭에서 찌그러지지 않게). 엠블럼을 바꾸면 `python3 tools/make_icons.py`로 다시 만들어요.

수식은 KaTeX, 글꼴은 Pretendard를 jsDelivr CDN에서 불러와요.
수업 자료의 강의 예제·복습문제·과제 유형을 바탕으로 새로 만든 개인 학습용 문제예요.
