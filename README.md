# Communications-Mathematics

기통수2 중간고사 문제은행 — 고려대학교 차세대통신학과 **기초통신수학 II (미적분학)** 중간고사 대비 사이트예요.
시험 범위 **Ch.12 벡터 ~ 16.4 그린 정리**의 개념 정리 한 페이지, 1~4단계 문제 은행(단계당 30문제, 총 120문제), 중간고사 예상 모의고사(10 + 5문항)로 구성돼요.

사이트 주소 (GitHub Pages): https://foy1229-maker.github.io/Communications-Mathematics/

예상 모의고사는 예상 유형 10개(극좌표 이중적분, 극한과 연속, 접평면·법선, 라그랑주 승수법, 이중적분, 삼중적분, 방향도함수·그래디언트, 선적분의 기본정리, 그린 정리, 최대 증가 방향)를 2025학년도 Calculus II(MATH 162, 다른 교수님) 중간·기말고사 난이도에 맞춰 만든 문제예요. 추가 5문항은 그 시험에 나왔지만 예상 목록에 없던 극값·안장점, 닫힌 영역의 최댓값·최솟값, 2계 연쇄법칙, 음함수 미분·선형근사, 12–13장 직선·평면·벡터함수예요.

## 로그인

서버가 없는 정적 사이트라 계정은 **이 브라우저(localStorage)에만** 저장되고 어디로도 보내지 않아요.

- **회원가입**: 이름, 아이디(영문 소문자로 시작하는 4~16자), 비밀번호(8~20자, 영문·숫자·특수문자 중 2가지 이상), 휴대폰 인증. 휴대폰 번호 하나에 계정 하나.
- **아이디 찾기**: 이름 + 휴대폰 인증 → 아이디와 가입일 표시.
- **비밀번호 찾기**: 아이디 + 휴대폰 인증 → 새 비밀번호 정하기 (지금 비밀번호와 같으면 안 돼요).
- **휴대폰 인증은 데모예요.** 실제 문자는 보내지 않고, 화면 위쪽에 문자 알림처럼 인증번호를 띄워요(누르면 자동 입력). 인증번호는 3분 동안 유효하고 5번 틀리면 다시 받아야 해요.
- **로그인 상태 유지**를 고르면 30일, 고르지 않으면 브라우저를 닫을 때까지 로그인돼 있어요.
- 맞음/다시 풀기 기록은 **계정마다 따로** 저장돼요. 로그인 기능이 생기기 전의 기록은 처음 로그인한 계정으로 옮겨져요.
- 비밀번호는 PBKDF2-SHA256 해시로, 휴대폰 번호는 SHA-256 해시와 가린 번호(010-\*\*\*\*-1234)로만 남겨요.
- 다른 기기·브라우저에서는 계정이 없으니 새로 가입해야 해요. 저장 공간을 쓸 수 없는 브라우저에서는 로그인 없이 열려요.

로그인은 문제 기록을 사람별로 나누는 용도이고 보안 장치는 아니에요(문제와 풀이는 원래 공개). 실제 문자로 인증하려면 Firebase 전화 인증 같은 유료 문자 서비스(사용량 과금)를 연결해야 해요.

## 문제 수정·추가

문제 원본은 `tools/level1.py` ~ `tools/level4.py`에 있고, 문제마다 sympy로 정답을 다시 계산하는 `check`가 붙어 있어요.

예상 모의고사 원본은 `tools/mock.py`에 있고, `check_all()`이 소문항 정답 70개를 sympy·mpmath로 다시 계산해요.

```bash
pip install sympy
python3 tools/build.py   # 120문제 정답 확인 → assets/problems.js
                         # 예상 모의고사 정답 70개 확인 → assets/mock-problems.js
```

`assets/problems.js`, `assets/mock-problems.js`는 자동 생성 파일이라 직접 고치지 말고 `tools/` 쪽을 고친 뒤 다시 빌드하세요.
`build.py`는 단계당 30문제, 단원별 문항 수, 모든 출제 유형에 문제가 1개 이상 있는지도 함께 확인해요.

## 구성

```
login.html          로그인 · 회원가입 · 아이디/비밀번호 찾기
index.html          대시보드
concepts.html       개념 정리 · 출제 유형
bank.html           문제 은행 (?level=1..4)
mock.html           중간고사 예상 모의고사
assets/
  session.js        로그인 상태, 로그인 안 했으면 login.html로 보내기, 사용자 메뉴
  login.js          로그인 화면 (계정 저장, 비밀번호 해시, 데모 휴대폰 인증)
  login.css         로그인 화면 스타일
  user-menu.css     오른쪽 위 사용자 메뉴 (이름 + 로그아웃)
  site.css          개념·문제 은행·모의고사 공통 스타일
  common.js         수식 렌더링(KaTeX), 풀이 기록 저장 (계정별)
  bank.js           문제 은행 화면
  concepts.js       유형별 연습 문제 링크, 목차 표시
  mock.js           예상 모의고사 화면 (풀이 시간, 기록, 문항 바로가기)
  problems.js       문제 데이터 (자동 생성)
  mock-problems.js  예상 모의고사 데이터 (자동 생성)
  img/              고려대 엠블럼, 본관 배경 사진, 파비콘
tools/              문제 원본(level1~4.py, mock.py)과 정답 검증·빌드 스크립트, 파비콘 만들기(make_icons.py)
```

파비콘은 세로로 긴 엠블럼을 정사각형 캔버스 가운데에 비율 그대로 놓은 것이에요(탭에서 찌그러지지 않게). 엠블럼을 바꾸면 `python3 tools/make_icons.py`로 다시 만들어요.

수식은 KaTeX, 글꼴은 Pretendard를 jsDelivr CDN에서 불러와요.
수업 자료의 강의 예제·복습문제·과제 유형을 바탕으로 새로 만든 개인 학습용 문제예요.
