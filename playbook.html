구의 방정식·등거리 집합

12.1

이런 문제구의 중심·반지름, 두 점에서 같은 거리에 있는 점들

행동강령

  1. $x^2,\ y^2,\ z^2$ 의 계수를 1로 맞추고 완전제곱 → $(x-h)^2+(y-k)^2+(z-l)^2=r^2$
  2. 우변 확인: $>0$ 이면 구, $=0$ 이면 한 점, $<0$ 이면 공집합
  3. 지름의 양 끝 $A,B$ 가 주어지면 중심 = 중점, $r=\tfrac12|AB|$
  4. 두 점 $A,B$ 에서 같은 거리: $|PA|^2=|PB|^2$ 를 전개 → 이차항이 지워져 평면 (법선 $\overrightarrow{AB}$, $AB$ 의 중점을 지남)
  5. 구와 좌표평면의 교선: 그 좌표에 $0$ 대입 (예: $xy$ 평면은 $z=0$) → 원의 중심·반지름

세부 체크

  • 완전제곱할 때 왼쪽에 더한 상수를 오른쪽에도 더했는지
  • “좌표평면에 접하는 구”: 반지름 = 중심에서 그 평면까지의 거리 (예: $xy$ 평면이면 $|l|$)

행동강령

사영(comp·proj)·평행/수직 성분

12.3 · 13.2

이런 문제스칼라 사영·벡터 사영, 평행·수직 성분으로 나누기, 접선 방향 가속도, 평면까지의 거리, 일

행동강령

  1. 무엇을 무엇 위로 사영하는지: $\operatorname{comp}_{\mathbf a}\mathbf b$ 는 $\mathbf b$ 를 $\mathbf a$ 방향으로 (아래첨자가 기준)
  2. $\mathbf a\cdot\mathbf b$ 와 $|\mathbf a|$ 를 먼저 계산
  3. 스칼라 사영 $\operatorname{comp}_{\mathbf a}\mathbf b=\dfrac{\mathbf a\cdot\mathbf b}{|\mathbf a|}$ (음수 가능)
  4. 벡터 사영 $\operatorname{proj}_{\mathbf a}\mathbf b=\dfrac{\mathbf a\cdot\mathbf b}{|\mathbf a|^2}\,\mathbf a$
  5. 수직 성분 $\mathbf b-\operatorname{proj}_{\mathbf a}\mathbf b$ → $\mathbf a$ 와 내적해서 $0$ 확인 → 크기
  6. 일: $W=\mathbf F\cdot\mathbf D$ ($\mathbf D$ = 끝점 − 시작점)

세부 체크

  • proj 의 분모는 $|\mathbf a|^2$ (제곱), comp 는 $|\mathbf a|$
  • 속도 $\mathbf v$·가속도 $\mathbf a$: 접선 성분 $\operatorname{comp}_{\mathbf v}\mathbf a=\frac{d}{dt}|\mathbf v|$, 수직 성분의 크기 $=\frac{|\mathbf v\times\mathbf a|}{|\mathbf v|}$ 로 검산
  • 점 $Q$ 와 평면: 거리 $=|\operatorname{comp}_{\mathbf n}\overrightarrow{P_0Q}|$, 가장 가까운 점 $=Q-\operatorname{proj}_{\mathbf n}\overrightarrow{P_0Q}$, 대칭점 $=Q-2\operatorname{proj}_{\mathbf n}\overrightarrow{P_0Q}$ ($P_0$ 는 평면 위 아무 점)

행동강령

  1. 점 $P_0$ + 방향 $\mathbf v$ → $\mathbf r=\mathbf r_0+t\mathbf v$ (두 점이면 $\mathbf v=\overrightarrow{P_0P_1}$, 두 평면의 교선이면 $\mathbf v=\mathbf n_1\times\mathbf n_2$)

14.4

이런 문제“정의를 이용해 미분가능함을 보이시오/판정하시오”, “$\Delta y=f'(a)\Delta x+\varepsilon\Delta x$ 임을 보이시오”

행동강령

일변수 증분식

  1. $\Delta x\ne0$ 일 때 $\varepsilon=\dfrac{\Delta y}{\Delta x}-f'(a)$ 로 정의
  2. 미분의 정의 $f'(a)=\displaystyle\lim_{\Delta x\to0}\frac{\Delta y}{\Delta x}$ 에서 $\varepsilon\to0$
  3. 양변에 $\Delta x$ 를 곱해 $\Delta y=f'(a)\Delta x+\varepsilon\Delta x$ ($\Delta x=0$ 일 때는 $\varepsilon=0$ 으로 정함)
  4. 구체적인 함수면 직접 전개: $g=x^3,\ a=1$ → $\Delta y=3\Delta x+\big(3\Delta x+(\Delta x)^2\big)\Delta x$

다항함수, 점 $(a,b)$ — 미분가능함 보이기

  1. 정의 문장부터 쓰기: $\Delta z=f_x\Delta x+f_y\Delta y+\varepsilon_1\Delta x+\varepsilon_2\Delta y$, $(\Delta x,\Delta y)\to(0,0)$ 일 때 $\varepsilon_1,\varepsilon_2\to0$
  2. $f_x(a,b),\ f_y(a,b)$ 계산
  3. $\Delta z=f(a+\Delta x,\ b+\Delta y)-f(a,b)$ 전개 → 1차항이 $f_x\Delta x+f_y\Delta y$ 인지 확인
  4. 남은 2차 이상 항을 $(\ \cdot\ )\Delta x+(\ \cdot\ )\Delta y$ 로 묶기 → 괄호가 $\varepsilon_1,\ \varepsilon_2$ (모두 $\Delta$ 를 포함해 $\to0$)

원점에서 따로 정의된 분수식

  1. $f_x(0,0),\ f_y(0,0)$ 을 정의로 (앞 카드)
  2. 미분가능 쪽: $\Delta z-f_x\Delta x-f_y\Delta y$ 를 $\varepsilon_1\Delta x+\varepsilon_2\Delta y$ 로 쓰고 $|\varepsilon_i|\le(\to0$ 인 식$)$ 로 조임 (예: $\varepsilon_1=\frac{(\Delta y)^2}{\sqrt{(\Delta x)^2+(\Delta y)^2}}$, $|\varepsilon_1|\le|\Delta y|$)
  3. 미분불가능 쪽: 미분가능하다고 가정 → $\Delta y=\Delta x$ 대입 → $\varepsilon_1+\varepsilon_2=$ ($0$ 이 아닌 상수) → $\varepsilon_i\to0$ 과 모순 (일반적으로 $\Delta y=m\Delta x$ 면 $\varepsilon_1+m\varepsilon_2$)

세부 체크

  • $\varepsilon_1,\varepsilon_2$ 는 유일하지 않음 — 다르게 묶어도 둘 다 $\to0$ 이면 정답
  • 편도함수 존재 ⇏ 미분가능, 편도함수가 연속 ⇒ 미분가능, 미분가능 ⇒ 연속
